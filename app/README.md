# منصة تنسيق حملات البلوقرز — نسخة تجريبية

منصة خفيفة لإنشاء حملات، نشر روابطها، تلقي تسجيلات البلوقرز مع اختيار موعد، اعتمادها من لوحة الأدمن، وإرسال تأكيد عبر الواتساب.

## المزايا
- صفحة عامة لكل حملة (`/campaign/<slug>`) مع نموذج تسجيل واختيار موعد من أوقات متاحة محددة.
- لوحة أدمن كاملة: إنشاء/تعديل الحملات، إدارة الأوقات، الموافقة/الرفض على السجلات.
- إشعار واتساب تلقائي عند الموافقة (وضع Stub حالياً — جاهز للربط بـ Meta Cloud API).
- واجهة عربية RTL، بدون أي تبعيات خارجية (Node.js 22 فقط).

## المتطلبات
- Node.js **22** أو أحدث (يستخدم `node:sqlite` المدمج).

## التشغيل

```bash
cd app
npm run seed    # زرع بيانات تجريبية (اختياري)
npm run dev     # تشغيل مع إعادة تحميل تلقائي
# أو
npm start
```

ثم افتح: http://localhost:3000

### بيانات الدخول الافتراضية للأدمن
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

يمكنك تغييرها عبر متغيرات البيئة قبل أول تشغيل:

```bash
ADMIN_USERNAME=myadmin ADMIN_PASSWORD=strongpass npm start
```

> البيانات تُحفظ في `data/app.db` (SQLite). لا ترفعها للـ Git.

## التدفق الكامل

1. الأدمن → `/admin/login` → ينشئ حملة ويضيف مواعيدها.
2. يشارك رابط `/campaign/<slug>` مع البلوقرز.
3. البلوقر يعبّي بياناته، يختار موعداً متاحاً، ويُرسل.
4. يظهر السجل في `/admin/registrations` بحالة "معلّق".
5. الأدمن يوافق → يتم إرسال رسالة واتساب (في وضع Stub تُطبع في الكونسول).

## ربط الواتساب الحقيقي

بعد الحصول على رقم واتساب تجاري واعتماد قالب رسالة على Meta:

```bash
WHATSAPP_TOKEN=<EAA...>        \
WHATSAPP_PHONE_ID=<123456>     \
WHATSAPP_TEMPLATE_NAME=campaign_approval_ar \
npm start
```

الكود في `lib/whatsapp.mjs` يبعث عبر Cloud API مباشرة بمجرد وجود هذه المتغيرات.

### مثال على قالب الرسالة (يُعتمد من Meta Business)

> مرحباً {{1}}، تم اعتماد حضورك في حملة "{{2}}" بتاريخ {{3}} بموقع {{4}}. نراك قريباً!

## الهيكل

```
app/
├─ server.mjs           # HTTP server + router
├─ seed.mjs             # زرع بيانات تجريبية
├─ lib/
│  ├─ db.mjs            # SQLite + schema + مساعدات
│  ├─ session.mjs       # كوكيز جلسة الأدمن (HMAC)
│  ├─ whatsapp.mjs      # إرسال الواتساب (stub / Cloud API)
│  └─ views.mjs         # قوالب HTML مع حماية XSS
├─ views/
│  ├─ public.mjs        # صفحات عامة
│  └─ admin.mjs         # صفحات الأدمن
├─ public/
│  └─ styles.css        # التنسيق
└─ data/
   └─ app.db            # قاعدة البيانات (تُنشأ تلقائياً)
```

## النقل لاحقاً

- **قاعدة البيانات**: الهيكل يستخدم SQL قياسي — انقله إلى PostgreSQL (Neon/Supabase) بتعديل طبقة `db.mjs` فقط.
- **الإطار**: المنطق منفصل عن طبقة العرض، يُنقل بسهولة إلى Next.js أو Express عند الحاجة.
- **النشر**: يكفي VPS بسيط أو Render/Fly.io مع ملف SQLite في وحدة تخزين ثابتة.
